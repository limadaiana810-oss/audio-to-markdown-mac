录音转写 · Mac 版 v2.5.1
=======================

从 GitHub Releases 下载 DMG，将「录音转写.app」拖入 Applications 后打开。
下载：https://github.com/limadaiana810-oss/audio-to-markdown-mac/releases/latest
无需输入命令。

1. 选择录音
点击左上角波形加号，按住 ⌘ 可多选；也可点击文件夹加号，加入该文件夹当前层的录音。
选中的文件会显示在列表里，可移除或清空。

2. 开始转写
点击右上角 ▶，窗口显示每份录音及总进度。悬停图标可查看用途。
录音在本机处理。默认沿用轻量模型、最多四个并发。
完成项变灰并移到底部，下一份自动补位；整批完成后恢复原顺序。
进度按真实完成的分段更新；较短录音可能直接从转写中变成完成。
点击 ■ 会保留已完成的内容，再点 ▶ 可以继续。

3. 取走一份 Markdown
底部显示「转写完成」后，点击文档图标查看，或向下箭头图标另存到你方便的位置。
把这一个 .md 文件交给 AI 做录音总结即可。

文稿格式示例（以下为示意文字）：

# 录音转写

## 2026-11-12 10:00:00–10:30:00

来源：会议录音_20261112_100000.wav

[00:00:12] 说话人1：今天先讨论项目进度。

[00:00:25] 说话人2：我先介绍目前的情况。

单个录音和多个录音都生成同样格式的一份文稿。
多份录音按文件名中的日期时间排序；时间不明的会明确标注。
段落时间戳相对于各自录音开头；不同录音中的同编号说话人不自动表示同一个人。
来源文件名保留，原文不由总结模型补写。没有正文的录音会保留说明。

结果位置
最近一次完整文稿：个人文件夹/录音转写/转写结果/合并全文.md
每批文稿另存于同级「合并全文」文件夹；窗口按钮始终打开本次结果。
某份失败时，窗口不会显示全部完成；重试可复用健康结果。

支持 Apple 芯片、macOS 14 或更新。DMG 内含离线环境、模型、中英文 README 和源码。
本版尚未经过 Apple Developer ID 公证；首次打开可能需在「隐私与安全性」中确认。
10 小时录音 5 分钟内完成是待验证目标；性能测量范围见 README。
原命令行入口保留；使用和修改说明见「README.md」。
